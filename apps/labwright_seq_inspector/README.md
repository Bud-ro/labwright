# labwright_seq_inspector

A standalone Flutter app for inspecting NI TestStand™ software `.seq` and `.ini` files.
Open a file with the file picker, drag-and-drop, or `flutter run -- path/to/file.seq`.
Supports the XML and binary (TOF1) formats.
