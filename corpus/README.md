# Test Corpus

The `.seq` and `.vi` sample files used to develop and measure the parsers, plus
small JSON snapshots of progress/coverage. The sample files themselves are
gitignored and fetched on demand (see the fetch tools below); only the JSON
indices and this README are committed.

## What "coverage" means lives with each parser

Coverage is measured and *defined* per package, because the VI and TestStand
formats are unrelated. Each package documents its complete metric taxonomy — every
axis, what 0 % and 100 % mean, and the rule that **the format is fully understood
IFF every axis reads 100 %** (so no axis is ever a hidden "part 2"):

- VI / RSRC: [`packages/labwright_rsrc_parse/COVERAGE.md`](../packages/labwright_rsrc_parse/COVERAGE.md)
- TestStand: [`packages/labwright_seq/COVERAGE.md`](../packages/labwright_seq/COVERAGE.md)

Run the per-package tools to regenerate the live scorecards:

```
dart run packages/labwright_rsrc_parse/tool/coverage.dart   # -> corpus/baseline.json + corpus/vi/REPORT.md
dart run packages/labwright_seq/tool/coverage.dart          # -> corpus/seq/REPORT.md
```

## Committed indices

- `baseline.json` — whole-corpus VI coverage, every axis (parse/decode/container/
  blocks-identified/block-bytes-decoded/heap-framed/heap-semantic/heap-complete).
  Generated by the VI coverage tool; read by `corpus_coverage_test.dart` as the
  regression floor. **Not hand-edited.**
- `snapshot.json` — per-VI feature presence (observed blocks, front-panel and
  block-diagram object counts); read by `corpus_snapshot_test.dart`.
- `sources.json` — VI corpus sources (GitHub repos + pinned commits).
- `seq-sources.json` — TestStand corpus sources, with an `encoding` field.

## Fetched samples (gitignored)

- `vi/`  — `dart run packages/labwright_rsrc_parse/tool/fetch_corpus.dart`
- `seq/` — `dart run packages/labwright_seq/tool/fetch_seq_corpus.dart`
