# labwright_rsrc_parse

A clean-room reader for the LabVIEW™ software RSRC container (`.vi` / `.ctl` / `.llb`).
Info about the format can be viewed here: https://labviewwiki.org/wiki/Resource_Container.

Currently all resources can be identified and have raw bytes dumped. Some resources 
already have decoders, but the eventual end goal of the project is to have proper viewers
and decoders for _every_ resource type.
